# SmartBin

Dual-sensor smart garbage bin: an ultrasonic sensor for volume and a load cell for weight, so a bin that is "full" by volume but far too light (a box bridging the top) is flagged **CHECK**, not FULL. One ESP32 drives both bins and connects by USB to a Raspberry Pi 5, which logs the readings and serves a live dashboard.

VIT University, SENSE, B.Tech ECE (Robotics & Automation). Vishal Ram K N, Thayanandhan P, Varun Vaishnav. Guide: Dr Kathirvelan J.

**Full guide (wiring, Pi setup, calibration): https://vishalramkn.github.io/smartbin/**

| Bin | Sensors |
|---|---|
| Bin 1 (left) | HC-SR04, 1 kg load cell + HX711, SG90 lid, FC-51 IR |
| Bin 2 (right, dummy) | HC-SR04, SG90 lid |

## Quick start on the Pi

```bash
git clone https://github.com/VishalRamKN/smartbin.git ~/smartbin
cd ~/smartbin && ./scripts/setup_pi.sh     # then log out and SSH in again
./scripts/flash.sh                         # build + flash the ESP32 over USB
binctl watch                               # live readings; dashboard on http://smartbin.local:8080
```

## Layout

```
firmware/   ESP32 (PlatformIO). Pins + bin geometry: firmware/src/config.h
hub/        Pi service: serial -> status rule -> SQLite -> dashboard/API -> cloud (optional)
scripts/    setup_pi.sh, flash.sh, binctl, udev rule, systemd unit
docs/       GitHub Pages site (wiring.svg is generated by docs/make_wiring_svg.py)
```
